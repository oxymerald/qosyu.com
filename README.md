# QOSYU — цифровая первая миля переработки

**QOSYU** — цифровая платформа первой мили экологической логистики.
Каждый день сотни кафе, магазинов и офисов выбрасывают по 10–20 кг картона и пластика —
для переработчиков такие объёмы нерентабельны. QOSYU объединяет разрозненные заявки малого
бизнеса в экономически выгодные маршруты: AI-кластеризация (DBSCAN), геооптимизация,
прозрачная ESG-отчётность.

```
Бизнес (кафе, магазины, офисы) → QOSYU (First Mile: объединяет заявки в маршрут) → Переработчик
```

## Возможности

- **Заявки на вывоз вторсырья** — сайт и Telegram-бот, заявка за 20 секунд
- **AI-кластеризация** — DBSCAN группирует соседние заявки в зоны сбора
- **Оптимизация маршрута** — OSRM с построением объезда, порядком точек, дистанцией
  и ETA; при недоступности OSRM — встроенная эвристика (nearest-neighbor + 2-opt),
  так что маршрут доступен всегда
- **AI-ассистент и рекомендации** — на Claude (Anthropic); без ключа платформа
  работает, аналитика переключается на rule-based ядро
- **Кабинеты трёх ролей** — бизнес (SME), переработчик, администратор
- **Админ-панель** — статистика, графики за 14 дней, распределение по типам,
  модерация пользователей, AI-инсайты
- **Мультиязычность** — русский, английский, казахский (мгновенное переключение,
  выбор сохраняется)
- **Telegram-уведомления** — привязка аккаунта по одноразовому коду, статусы вывоза
- **Чат** между бизнесом и переработчиком (WebSocket)
- **Маркетплейс вторсырья** — объявления, заказы, статусная машина
- **ESG-отчётность** — кг переработанного сырья, CO₂, эквивалент деревьев
- **Отзывы и рейтинги** переработчиков

## Стек

| Компонент | Технологии |
|---|---|
| Бэкенд | Python 3.11, FastAPI, SQLAlchemy 2 (async) |
| БД | PostgreSQL 15 + PostGIS |
| Кэш / rate-limit | Redis |
| AI-кластеризация | scikit-learn (DBSCAN) |
| Auth | JWT (короткоживущие access-токены) + bcrypt |
| Фронтенд | Ванильный HTML/CSS/JS + Leaflet (без сборщиков) |
| Инфраструктура | Docker Compose |

## Безопасность

- Секреты только в `.env` (см. `.env.example`), в репозитории секретов нет
- Rate limiting на все чувствительные эндпоинты (Redis + fallback в память):
  логин — 5 попыток / 15 мин на IP+email, регистрация — 10 / час
- Единые сообщения об ошибках входа (нет утечки, существует ли email)
- Парольная политика (≥8 символов, буквы + цифры), bcrypt
- Роль `admin` недоступна при самостоятельной регистрации; админ создаётся
  через `ADMIN_EMAIL`/`ADMIN_PASSWORD` при старте
- Security headers: CSP, X-Frame-Options, nosniff, Referrer-Policy, HSTS (prod)
- Лимит размера тела запроса (1 МБ), лимиты пагинации, валидация всех входных данных
- Экранирование любых пользовательских данных на фронтенде (защита от XSS)
- WebSocket-чат: проверка токена и получателя, лимит длины и частоты сообщений
- Блокировки строк БД (`SELECT … FOR UPDATE`) против гонок в зонах и заказах
- Docker: non-root пользователь, Redis не публикуется наружу, БД — только на 127.0.0.1
- В production API-документация (`/docs`) отключена, стектрейсы не раскрываются

> ⚠️ **Важно:** в старой версии репозитория токен Telegram-бота был закоммичен в открытом
> виде. Этот токен скомпрометирован — **отзовите его у @BotFather** (`/revoke`) и получите
> новый. Новый токен храните только в `.env`.

## Запуск

### 1. Подготовка

```bash
git clone https://github.com/oxymerald/qosyu.com.git
cd qosyu.com
cp .env.example .env
# Заполните .env: POSTGRES_PASSWORD, SECRET_KEY (обязательно), остальное по желанию
python -c "import secrets; print(secrets.token_urlsafe(64))"   # для SECRET_KEY
```

### 2. Старт

```bash
docker compose up -d --build
```

Сайт: http://localhost:8080 · API-документация (dev): http://localhost:8080/docs

### 3. Остановка

```bash
docker compose down
```

## Структура

```
qosyu.com/
├── app/
│   ├── routers/          # auth, requests, recycler, clustering, analytics,
│   │                     # chat, marketplace, reviews, push, telegram_bot
│   ├── services/         # geo (DBSCAN + OSRM), esg, chat_manager
│   ├── static/           # фронтенд: index.html, css/, js/
│   ├── models.py         # SQLAlchemy-модели
│   ├── schemas.py        # Pydantic-схемы (валидация)
│   ├── security.py       # rate limiter, security headers, лимит тела
│   ├── auth.py           # JWT, bcrypt, парольная политика
│   ├── dependencies.py   # get_current_user, require_roles
│   └── main.py           # точка входа FastAPI
├── docker-compose.yml
├── Dockerfile
├── .env.example
└── requirements.txt
```
