# ♻️ QOSYU — AI‑агрегатор сбора вторсырья

**QOSYU** – это B2B‑платформа, которая превращает разрозненные отходы малого бизнеса в прибыльную цепочку поставок для переработчиков.  
С помощью геопространственного AI мы кластеризуем заявки, оптимизируем маршруты и даём прозрачную ESG‑отчётность.

> 🚀 **Проект полностью рабочий «из коробки»** – бэкенд, фронтенд, чат, маркетплейс.

---

## 📦 Основные возможности

- **Двусторонний маркетплейс**  
  Переработчики создают объявления с ценой за кг, SME заказывают вывоз в один клик.

- **AI‑кластеризация заявок** (DBSCAN)  
  Группируем близкие заявки в зоны сбора, сокращаем пробег машин до 40%.

- **Встроенный чат**  
  SME и переработчик могут общаться по каждой зоне или в общем диалоге.

- **ESG‑отчётность в реальном времени**  
  Автоматический расчёт CO₂, сохранённых деревьев, тонн переработанных отходов.

- **Интерактивная карта** (Leaflet)  
  Визуализация всех заявок, зон сбора и статусов.

- **Готовая инфраструктура Docker**  
  Запуск в трёх контейнерах: PostgreSQL+PostGIS, Redis, бэкенд FastAPI.

## 🚀 Как запустить проект (локально)

### 1. Установите Docker Desktop
- Скачайте с [официального сайта](https://www.docker.com/products/docker-desktop/) для Windows / macOS / Linux.
- Запустите Docker Desktop и дождитесь, пока иконка в трее перестанет мигать.

### 2. Склонируйте репозиторий
```bash
git clone https://github.com/justsummon/qosyu-project.git
cd qosyu-backend
```
### 3. Запустите все сервисы одной командой
```bash
docker compose up -d --build
```
Первый запуск займёт 2–3 минуты (скачивание образов, установка Python-пакетов).
В следующий раз запуск будет мгновенным.

4. Откройте сайт в браузере
Перейдите по адресу: http://localhost:8000
Лендинг с описанием и тарифами.

Регистрация / вход – кнопки в правом верхнем углу.

После входа – личный кабинет с картой, чатом, маркетплейсом.

5. Запуск фронтэнда - запустите index.html
6. Остановка (когда закончите)
```bash
docker compose down
```
