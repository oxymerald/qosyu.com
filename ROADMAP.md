# QOSYU — этапы доработки

Утверждённое направление: светлый интерфейс с бордовыми акцентами, карта и
планирование в браузере. GPS-навигация не входит в текущий этап.

1. Заявки: адрес, описание подъезда, совместимое обновление базы и проверка сохранения.
2. Кабинет: карта как главный экран, поиск, карточки, остановки и мобильная нижняя панель.
3. Маршруты: дорожные расстояния для порядка остановок, ограничения и проверка MapGL.
4. Подготовка: честная главная страница, ограничения API, резервное копирование, регрессия.

Каждый этап проверяется на отдельной базе. Секреты и резервные копии базы в Git не входят.
Состояние этапов и фактические ограничения фиксируются по результатам проверок.

## Состояние на 7 октября 2026

- Этап 1 завершён: адрес и примечание сохраняются, выводятся в заявках и остановках.
  Проверена повторная миграция существующей таблицы. На рабочей базе сохранились
  все 11 прежних заявок; их новые поля остаются пустыми.
- Этап 2 завершён: светлый кабинет, карта занимает доступный экран, мобильная
  панель сворачивается, остановки маршрута выбираются нажатием. Новая главная
  страница описывает действующие функции без неподтверждённых чисел и тарифов.
- Этап 3: дорожный порядок реализован для 2–8 остановок через Distance Matrix,
  доступны кэш и дневной бюджет. Проверен настоящий ответ 2ГИС с двумя остановками.
  Векторная карта MapGL остаётся следующим этапом: доступ к Map Tiles подтверждён
  владельцем; перед подключением нужен отдельный браузерный ключ с узкими правами.
  Текущий серверный ключ не выдаётся браузеру.
- Этап 4: пройдён 41 серверный тест на отдельной базе; в браузере проверены создание,
  история, маршрут, назначение, завершение, адреса с HTML как обычный текст,
  мобильная панель, резервная карта и помощник. Провайдеры в UI-тестах имитировались;
  дорожный расчёт отдельно проверен на настоящем API. Архив базы успешно восстановлен
  в отдельную временную базу. Дамп и ключи исключены из Git и сборочного контекста.

## Следующий этап: MapGL

1. Подключить отдельный браузерный ключ Map Tiles, ограниченный адресами сайта.
2. Перенести маркеры, зоны, выбор точки и маршруты на векторный движок.
3. Проверить поворот, наклон, подписи, WebGL и резервный режим на ноутбуке и телефоне.
4. После проверки заменить текущий движок. GPS-навигация остаётся вне этого этапа.
